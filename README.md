## Requirements
Install a Java Development Kit (JDK). To check the installation, run:
```bash
java -version
javac -version
```

## How to compile and run
Open a terminal in the relevant folder and run the commands below.

### Week 1
```bash
cd week01
javac FirstProgram.java
java FirstProgram
```

### Week 2
```bash
cd week02
javac HelloWorld.java
java HelloWorld
javac StudentProfile.java
java StudentProfile
```

### Week 3
```bash
cd week03
javac SimpleCalculator.java
java SimpleCalculator
javac AverageCalculator.java
java AverageCalculator
javac ItemCost.java
java ItemCost
```

If you are already inside a week's folder, do not run `cd` into that same folder again.

## Week 3 programs
1. `SimpleCalculator.java` reads two numbers and displays their sum, difference, product and quotient. It handles division by zero.
2. `AverageCalculator.java` reads a student's name and three scores, then displays the total and average.
3. `ItemCost.java` reads an item name, quantity and unit price, then calculates the total cost.
